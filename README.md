# 🏦 Customer Churn Analytics for the Banking Industry | SQL Project

## 📌 Objective
To analyze and understand customer churn patterns within a banking dataset using SQL queries and statistical techniques.  
The goal is to identify key factors influencing churn and propose actionable insights to improve customer retention.

---

## 🧠 Project Overview
This project explores **10,000+ customer records** to uncover churn drivers across demographics, geography, and financial behavior.  
The entire analysis was performed using **SQL**, focusing on both data manipulation (DML) and definition (DDL) queries.

---

## ⚙️ Tools & Technologies
- **SQL** (Structured Query Language)  
- **MySQL / PostgreSQL** (for querying and analytics)  
- **Excel / PowerPoint** (for visualization and presentation)  

---

## 📊 Key Analyses Performed
| Analysis Type | Description |
|----------------|-------------|
| **DDL / DML Queries** | Created and managed tables; inserted, updated, and queried churn data |
| **Churn by Age Group** | Highest churn observed in customers aged **46–60** |
| **Gender-wise Churn** | Slightly higher churn among male customers |
| **Geography-wise Churn** | Certain regions show distinct churn behavior |
| **Financial Behavior** | Customers with fewer products and low activity have higher churn |
| **Credit & Balance Stats** | Outlier detection using mean, median, and standard deviation |
| **Inactive Users** | Inactive customers are **6× more likely** to churn |

---

## 🔍 Insights & Findings
- 🧾 **Inactive customers** pose the greatest churn risk.  
- 👨‍💼 **Mid-age segment (46–60)** shows the highest churn tendency.  
- 📉 **Single-product users** churn **2–3×** more than multi-product users.  
- 💳 **Low engagement** and **limited product adoption** are key risk drivers.  
- 🌍 **Regional patterns** reveal targeted opportunities for retention campaigns.

---

## 💡 Business Recommendations
| Segment | Actionable Ideas |
|----------|------------------|
| **Inactive Customers** | Reactivation campaigns via email/SMS; rewards for returning users; automated 30-day triggers |
| **Mid-Age Customers (46–60)** | Financial wellness content, advisory programs, tenure rewards |
| **Single Product Users** | Cross-sell bundled offers; incentivize multi-product adoption |
